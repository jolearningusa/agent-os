# PR #13 合理性与可行性复核

日期：2026-11-15。基于 main `069a8a3` 和已合并的
[PR #13](https://github.com/jolearningusa/agent-os/pull/13)。评估范围为交付计划与决策记录，
本次采用静态依赖与验收分析，Hermes/Ollama 和目标平台测试待实施提供。

修订后的执行入口为 [本地交付计划](../plans/local-harness-deliveries.zh-CN.md)。

## 合理性与可行性判断

Hermes 单一 Harness、先 mock 探针再建设正式启动器的方向合理。工具循环与摘要
调用是核心观察目标，将探针独立于 L1 有助于先验证价值。浏览器 cookie 与 CLI 授权头
分离、观测开销独立测量也具备可实施的工程路径。

当前可推进 L0a 决策和 L0b mock 探针。真实模型闭环有条件可行，前置条件包括固定
Hermes 提交的采集能力、目标平台的网络/文件隔离，以及模型容量。现有文档无法证明
这些条件已满足，16–29 人日估计继续作为探针完成前的粗估区间。

## 发现、修改与理由

### R1 高优先级，mock 降级与真实路径门禁不一致

PR #13 允许真实网络隔离无法实现时仅在 mock 验收 L23/L36，但原退出条件仍要求
全通过。执行者可能将 mock 证据当作真实环境完成，也可能因解释冲突停滞。

本次明确 mock/真实环境分别记录。mock 开发可以继续；真实路径的隔离子项标记
blocked，L2/L3 与首个可用版本保持未完成。L36 拆分留存网络、文件及工具证据，
网络限制缺失不能豁免文件隔离。L0a 用最小 canary 检查网络机制，L0b 复用，
消除“必须先运行 Hermes 才能完成 L0a”的隐性依赖。

验证方式为 ADR、平台配置及允许/拒绝 canary 结果相互对应；真实路径验证通过后
再运行模型任务。阻塞状态必须在 PR 证据清单和计划中同时可见。

### R2 中优先级，独立探针的复现与退役条件不充分

最小启动方式解决了循环依赖，但手工安装步骤和临时脚本可能漂移，使 L02 通过
难以复现，或使 L1 后保留两套不一致入口。

本次要求探针脚本/配置入库、从空实验目录按记录命令复跑，区分安装期下载和执行期
mock 网络限制，清空继承模型凭据。L1 替换入口时复跑同一 fixture 并核对观察契约，
随后移除旧入口。由此保留最小探针的低成本，同时让证据可重复。

### R3 中优先级，cookie 鉴权缺少首次建立会话的流程

PR #13 解决了 cookie 与授权头混用，却没有说明浏览器首次如何取得可信会话。
HttpOnly cookie 与 CSRF token 的可读性也应分开描述。

本次在 L43 采用终端短时单次配对码，页面手工提交，成功后轮换会话；配对请求检查
Host/Origin、限制尝试，过期和重用均拒绝。退出/重启使旧会话失效。浏览器可读的
CSRF token 绑定当前会话，认证 cookie 保持 HttpOnly，CLI 凭据走独立校验路径。
这是本修订选择的首次登录方案，具体有效期和限流值在 L0a 固定并测试。

### R4 中优先级，采集开销测量的控制变量与用途冲突

L54 开关采集的对比合理，但关闭采集后不能依赖该采集器报告失败和完整性。
模型波动、历史与缓存变化也会影响延迟差，无法直接将差值全部归因于采集。

本次引入独立测试驱动、配对运行、交替顺序、相同初始会话状态及预登记 N。
提交到完整响应与事件落盘分别计时，失败计入汇总；报告差值与离散程度，保留原始
结果。关闭采集的运行专用于开销实验，完整上下文基线仍只接受采集完整的运行。

### R5 低优先级，验收标题及证据状态需统一

L2/L4 标题范围分别止于 L24/L43，但正文包含 L25/L44。本次修正标题，并为全部
验收统一定义 pass/fail/blocked/not-run 及证据字段，已有 36 个验收编号保持兼容。
复用同一清单可以降低后续 PR 判断“完成”的歧义。

## 保留的决策与后续动作

PR #13 的实施基线草案状态、建议值由 ADR 确认、L3 工期探针后重估均保留。
本次修订集中在现有交付的完成条件，下一实现切片按 L0a 执行，之后才交付 L0b。

文档检查脚本入库仍是 L06 的待交付项。待实现时先完成确定性 mock 和负面用例，
再运行隔离后的本地模型；这一顺序可减少硬件与模型随机性对工程验证的干扰。

## 验证与回滚

本次检查相对链接、尾随空白、围栏、末尾换行、36 个验收 ID 的唯一性与编号引用，
并复核 R1–R5 已写入计划。运行时、安全机制及开销实验的验收均待实施。
文档回滚可还原本次改动，无部署、依赖和持久化 schema 变更。
